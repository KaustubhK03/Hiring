1) GET /user-profile/

Fetches the authenticated user’s ATS (Applicant Tracking System) profile data, including:
	•	ATS Score
	•	Missing Keywords
	•	ATS Remarks

Example Response
{
  "ats_score": 85,
  "missing_keywords": ["machine learning", "deep learning", "Python"],
  "ats_remarks": "Your resume is well-structured, but consider adding more keywords related to AI."
}

If the user has no associated Profile, the response will be:

{
  "ats_score": "No Score Available",
  "missing_keywords": [],
  "ats_remarks": "No remarks available"
}

2) Track Task Progress

Endpoint: GET /progress/<task_id>/
Function: views.task_status
Description:
Polls the progress of a resume parsing task initiated via Celery. Returns status updates and final ATS data upon completion.

Request Type: GET
Authentication: Required (request.user.is_authenticated)
Path Parameters:
	•	task_id: UUID of the background task

Response Examples:
	•	In Progress:
    {
    "status": "PROGRESS",
    "progress": 40.0,
    "description": "Calculating ATS Score"
    }

    •	Completed:
    {
    "status": "SUCCESS",
    "ats_score": 87.0,
    "missing_keywords": ["Leadership", "Scrum"],
    "ats_remarks": "Well-aligned resume. Minor keyword additions needed."
    }

    •	Failure:
    {
    "status": "FAILURE"
    }

3) Save Admin Settings

Endpoint: POST /save-admin-settings/
Function: views.save_admin_settings
Description:
Saves system-wide admin configurations like LLM model, quiz settings, time limits, etc.

Request Type: POST
Authentication: Admin-only (@user_passes_test(lambda u: u.is_superuser))

Response Example:

}

9)  Internal Utility: create_submission()
	•	Used by: /get_code_from_frontend/
	•	Function: Creates a code submission by sending it to the Judge0 API.
	•	Returns: Token for fetching results.

    Sample Request (Internal):
    {
    "language_id": "52",
    "source_code": "<base64 encoded>",
    "stdin": "<base64 encoded>"
    }

10) Internal Utility: get_submission(token)
	•	Used by: /get_code_from_frontend/
	•	Function: Fetches execution result using a Judge0 token.
	•	Returns: stdout, compile errors, memory usage, etc.

    URI Parameters

    token
        string (required) Example: d85cd024-1548-4165-96c7-7bc88673f194

        Token of submission. You got this token when you created submission.
    base64_encoded
        boolean (optional) Example: false

        Set to true if you want to receive Base64 encoded data from Judge0. You should set this to true if you expect the program’s stdout to contain non-printable characters or if you expect the compiler to output non-printable characters during a compile error (GCC does this, for instance).
    fields
        string (optional) Default: stdout,time,memory,stderr,token,compile_output,message,status Example: stdout,stderr,status_id,language_id

        Return only the desired attributes.
    
    Headers

    Content-Type: applicatiion/json

    Body

    {
    "stdout": "hello, world\n",
    "status_id": 5,
    "language_id": 4,
    "stderr": null
    }
